1. 选择设备与场景

每次操作替换当前注入配置。切换目标后需点击注入才生效。停止不会清空累计错误或历史事件，也不会自动确认XID告警恢复。

2. 在夜莺查看

打开夜莺的“数据查询 → 指标”，选择数据源 GPU主清单模拟-原始指标，查看最近15分钟。

打开夜莺

XID是离散错误码，不是幅值。重复注入相同XID，最近码曲线可能不变，但下方会新增独立事件记录。持续确认和通知存在正常延迟。
