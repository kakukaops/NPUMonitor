## 2. 核心行为

- 真实采集到10秒短暂高温，但没有触发持续30秒的温度规则。
- XID及DBE告警定位第一张卡；ECC窗口退出表示近期无新增，不表示硬件修复。
- ECC计数器重置没有生成新的计数新增告警。
- 采集HTTP 503仅触发采集失败；没有同时发出设备指标消失通知。
- 单卡指标消失定位第二张卡；全卡指标消失分别产生两张卡的告警和恢复通知。
- 正向用例均核对触发与恢复hash一致、规则身份及UUID，并检查没有其他实验规则的通知误报。

## 3. 发现并修复的问题

原始NaN表达式 `temperature != temperature` 返回样本仍为NaN，实测没有形成夜莺告警。已改为 `(temperature != bool temperature) == 1`，以有限值1表示无效输入，定向重测通过。迁移仅在旧表达式完全匹配时更新，不覆盖其他规则字段或本地改写的表达式。
