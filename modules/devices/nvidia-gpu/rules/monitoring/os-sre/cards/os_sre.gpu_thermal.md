# GPU达到运行温度门槛

规则 `os_sre.gpu_thermal`，版本0.2.0；默认disabled；状态 `candidate`。

## 身份与输入

匹配标签：`job,instance,UUID`。不依赖集群ID、业务任务、租户或作业状态。
输入：`DCGM_FI_DEV_GPU_TEMP`、`DCGM_FI_DEV_GPU_MAX_OP_TEMP`。

## 语义与边界

使用设备门槛；5°C回差为工程参数。缺少任一有效输入不提供恢复证据。
持续确认：60秒（工程配置）；真实硬件与夜莺新版本接入尚未验收。

## 来源与参数依据

| 项目 | 内容 |
|---|---|
| 官方语义 | GPU温度和对应设备门槛字段；温度/时钟管理语义。 |
| 具体来源 | [nvidia.dcgm.fixed_fields](https://github.com/NVIDIA/DCGM/blob/9fae2867e6e5264fa0fca22a07dc898d591baa21/dcgmlib/dcgm_fields.h)；[nvidia.smi](https://docs.nvidia.com/deploy/nvidia-smi/index.html) |
| 项目判据 | 门槛减当前温度<=0为异常观测；余量>5°C才给解除观测。 |
| 参数来源 | P05=5；P03=60；P04=30；P09=2；P01=90；P08=按metrics.yaml逐字段约束；P10=job/instance + 硬件ID；预期清单默认空 |
| 证据边界 | 合成向量求值；不包括新版持续确认/夜莺/真实设备/生产案例；生产案例无；真实硬件未验 |
| 待核实项 | 门槛取设备读数，5°C回差和持续确认不是官方统一参数。 |
