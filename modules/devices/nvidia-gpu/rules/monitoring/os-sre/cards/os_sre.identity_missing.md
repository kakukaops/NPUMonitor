# 硬件身份标签缺失

规则 `os_sre.identity_missing`，版本0.2.0；默认disabled；状态 `candidate`。

## 身份与输入

匹配标签：`job,instance,metric_name`。不依赖集群ID、业务任务、租户或作业状态。
输入：采集目标/监控组件指标或OS资产清单。

## 语义与边界

UUID/switch_id/link_id缺失时明确报采集契约缺口，不按序号伪造设备身份。
持续确认：60秒（工程配置）；真实硬件与夜莺新版本接入尚未验收。

## 来源与参数依据

| 项目 | 内容 |
|---|---|
| 官方语义 | job/instance由采集配置提供；稳定硬件键不是Prometheus自动保证。 |
| 具体来源 | [prometheus.up](https://prometheus.io/docs/concepts/jobs_instances/)；[prometheus.operators](https://prometheus.io/docs/prometheus/latest/querying/operators/) |
| 项目判据 | 缺UUID/switch_id/link_id报契约缺口，不用卡序号伪造身份。 |
| 参数来源 | P10=job/instance + 硬件ID；预期清单默认空；P03=60；P04=30；P09=2；P01=90 |
| 证据边界 | 合成向量求值；不包括新版持续确认/夜莺/真实设备/生产案例；生产案例无；真实硬件未验 |
| 待核实项 | 这是本项目采集契约，不是NVIDIA官方故障规则；不从空结果推断健康。 |
