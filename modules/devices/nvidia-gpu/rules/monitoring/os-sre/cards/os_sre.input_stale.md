# 测量样本陈旧

规则 `os_sre.input_stale`，版本0.2.0；默认disabled；状态 `candidate`。

## 身份与输入

匹配标签：`job,instance,metric_name`。不依赖集群ID、业务任务、租户或作业状态。
输入：采集目标/监控组件指标或OS资产清单。

## 语义与边界

演示15秒，生产候选90秒。
持续确认：60秒（工程配置）；真实硬件与夜莺新版本接入尚未验收。

## 来源与参数依据

| 项目 | 内容 |
|---|---|
| 官方语义 | timestamp返回样本时间；不证明Exporter内部缓存刷新时间。 |
| 具体来源 | [prometheus.functions](https://github.com/prometheus/prometheus/blob/v3.2.1/docs/querying/functions.md) |
| 项目判据 | 样本年龄超过配置值或为负数，且采集目标健康。 |
| 参数来源 | P01=90；P03=60；P04=30；P09=2 |
| 证据边界 | 合成向量求值；不包括新版持续确认/夜莺/真实设备/生产案例；生产案例无；真实硬件未验 |
| 待核实项 | 这是本项目采集契约，不是NVIDIA官方故障规则；不从空结果推断健康。 |
