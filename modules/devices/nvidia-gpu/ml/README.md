# GPU机器学习监控模块

**正式指标规范源：**[第14篇GPU监控指标与告警规则说明表](../rules/docs/14-GPU监控指标与告警规则说明表.md)。模拟数据、规则和ML输入统一遵循；公共契约与ML输入契约为自动派生，旧台账不能覆盖此规范。


当前代码版本 **0.7.0 / 动态基线与远程模型登记**（已启动模拟服务，浏览器视觉待验收）。监控页面 **http://localhost:19460**，本地参考模型服务health为 **http://localhost:19461/health**。

## 两类核心能力

1. 单指标动态基线与异常检测：基于此前样本预测当前点，展示实际曲线、动态参考、参考带及异常；模型参数当前不在线更新。
2. 多指标联合异常检测：学习同卡多个指标的组合/关系，输出联合评分及算法支持的重构或条件证据。

四类DCGM条件关系/残差漂移是第二类能力的应用模板，独立模型平台是共同支撑。单指标参考带当前为训练残差固定尺度，并非自适应概率区间；通用联合模型主要分析当前点组合，不代表通用多变量时序或跨卡检测。

2026-11-17已完成文档对齐；判定分量展示、双能力专项验收、浏览器实际交互及真实长期效果仍待完成。详见[需求](docs/01-需求文档.md)、[方案](docs/02-技术方案.md)和[计划](docs/03-项目计划.md)。此前文档修订未改变0.5.1；本轮代码增量为0.6.0，部署状态见演示记录。

指标选择先按[动态基线适用性与准入清单](docs/15-GPU指标动态基线适用性与准入.md)核对：首批5项、当前3项条件候选；正式103项均登记去向。首批5项入口与初步适用性预检已实现，完整分级筛选与真实效果仍待验收。

## 职责

- 本模块：DCGM数据、GPU场景、特征、仿真、任务编排、GPU Web/API及夜莺对象绑定。
- `../adapters/nvidia_gpu_ml/`：NVIDIA条件检测、残差漂移与历史模型实现。
- [公共平台](../../../platform/README.md)：共享查询传输、夜莺HTTP传输和监控存储。
- [模型服务](../../../model-services/README.md)：模型协议、HTTP适配器、通用算法及独立训练/部署/评分。

新训练不在监控进程执行，新权重不写入监控模型目录。训练、校准/集成版本和API评分由独立服务完成。旧本地模型仍可检测、回放和回滚；修改旧制品需要先在目标平台重训，不自动上传pickle。

## 首批指标演示

入口为“动态基线”：首批5项指标、已有模型参数查看、历史训练参数配置、判定分量和异常注入。详见[演示与验收记录](docs/16-单指标动态基线演示与验收.md)。

```bash
bash scripts/experiment.sh start
bash modules/devices/nvidia-gpu/ml/scripts/gpu-ml.sh prepare-baseline
# 关闭：bash scripts/experiment.sh stop
```

统一脚本负责启停，prepare-baseline仅准备模拟参考数据和模型，不启动/关闭服务；正常参考与Prometheus实际历史明确区分。已通过统一启动入口启动模拟服务，5项在线基线有效，49项监控与9项模型平台测试通过；浏览器视觉待验收。

## 启动与使用

```bash
bash modules/devices/nvidia-gpu/ml/scripts/gpu-ml.sh simulation-up
bash modules/devices/nvidia-gpu/ml/scripts/gpu-ml.sh status
# 仅启动参考模型服务
GPU_ML_SIMULATION=true bash modules/devices/nvidia-gpu/ml/scripts/gpu-ml.sh platform-up
# 平台独立备份
bash modules/devices/nvidia-gpu/ml/scripts/gpu-ml.sh platform-backup
```

页面角色直登保持，训练入口不变；平台状态可在“平台与审计”查看。发布先部署成功再切换指针，失败不自动改模型。平台超时/错误标未知，不补正常值；外部任务重启后同步，不盲目重复提交。

当前数据仅DCGM，通用单指标/多指标配置保留，并提供四类应用场景：条件热关系、功耗/时钟关系、热残差长期漂移、时钟残差长期漂移。场景默认仅证据，production和加速laboratory隔离；不增加作业、吞吐或环境信息，不认定硬件老化或预测寿命。

## 公司平台替换

实现ModelBackend原生SDK适配器，或提供内部协议兼容HTTP桥接。GPU_ML_MODEL_PLATFORM_URL配置兼容桥接地址时，启动脚本不再启动本地参考平台；GPU_ML_MODEL_BACKEND_ID标识独立后端命名空间，凭据来自私有文件。不能把任意公司模型URL直接填入后期待兼容。

已增加[远程模型服务连接与已有部署登记](docs/17-远程模型接入与登记.md)，可按模型引用调用多个服务；历史训练仍使用一个默认后端。真实公司API尚未提供，目前已验证同机独立参考服务的完整HTTP链路，没有对接真实公司平台。不做跨后端引用自动迁移；已有API模型应计划重训/迁移与切换，不能把旧model_ref直接发给新平台。旧本地模型不受这个URL切换影响。
