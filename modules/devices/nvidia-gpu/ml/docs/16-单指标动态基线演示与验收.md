# 单指标动态基线：演示与验证记录

日期：2026-11-17；代码版本：0.6.0。状态：已部署0.6.0；统一启动入口通过，5项在线基线有效，43项监控测试与8项模型平台测试通过。浏览器视觉/实际点击仍未验收。

## 实现范围

首批gpu_temp、memory_temp、power、util、mem_util分别建立单指标任务。Web首页为“动态基线”，提供每GPU五张指标卡，可准备模拟参考模型、选择已有模型、从历史训练、查看曲线和调整运行参数。旧场景、通用多指标和历史模型入口保留。

已有模型展示固定采样周期、窗口、alpha、预处理、校准和判定参数，只选择通过自检、同实体/模板/来源且后端兼容的版本。服务端发布还检查完整输入schema与部署回执。修改权重相关参数需训练新版本；修改校准使用原有后处理入口；运行阈值倍率、异常/恢复样本数写入任务revision，下一新鲜源样本按新修订重新累计确认。默认仍为3/3，未知保持已有异常。

训练支持Prometheus实际采集历史与显式模拟正常参考两种数据来源，默认选择实际采集历史；参考来源仅在显式模拟环境、已知模拟UUID和首批单指标任务允许使用，不作为缺失历史的自动回退。预置参考通过同一healthy生成函数生成1小时正常数据，快照单独保存，来源为simulation-reference；在线数据仍从Prometheus读取，参考训练数据不写入在线曲线或伪装成已采集历史。

训练参数包括历史窗口/自定义时间、整数采样步长、预处理、滞后窗口4～60点、Ridge alpha 0.001～1000、两个校准分位数0.9～0.9999、初始阈值倍率0.8～2。level_mad等非时序算法不提交窗口/alpha。模型记录alpha并保持历史缺省1的兼容。

输入预检记录取值数、合法零值占比、最小/最大值、连续时间对与缺口，拒绝非有限/重复时间和训练段不足3种取值的动态预测；仍需现场评估工况代表性。模型报告增加独立比较段/测试段相对上一值和训练中位数的原单位MAE，不将预测误差称故障准确率。

实时证据保存预测残差与水平偏离分量；页面解释带内异常与固定残差带。新增功耗突增和显存活动下降注入，温度尖峰覆盖GPU/HBM，活动下降覆盖利用率；所有注入仅对模拟GPU可用。

## 启动与人工检查

前提：Docker可用，现有隔离lab的Prometheus/夜莺及gpu-alert-lab_default网络已经启动；不改生产数据源。仓库根目录执行：

```bash
bash scripts/experiment.sh start
bash modules/devices/nvidia-gpu/ml/scripts/gpu-ml.sh prepare-baseline
# 关闭服务
bash scripts/experiment.sh stop
```

服务启停统一使用scripts/experiment.sh；代码更新需构建部署时使用模块原有simulation-up，不新增启停入口。prepare-baseline仅初始化数据，等待采集第一张模拟GPU，准备5项任务和正常参考模型，为尚未发布的任务发布参考版本，再等待5项在线基线有效。已存在的在线指针、退役任务和人工设置不覆盖；新建演示任务默认仅证据。Web自身的“准备模拟演示模型”按钮仅排队训练，不自动发布。重复执行不盲目重复训练已验证的参考版本。

启动成功后访问http://localhost:19460，选择管理员角色进入。“动态基线”页选择GPU-ML-SIM-0000，逐项查看曲线。在线结果实时积累，刚启动时历史展示较短，不能用参考训练快照补出过去在线曲线。

1. 在“使用已训练的基线”查看固定参数并选择版本，确认在线版本更新。
2. “重新学习历史基线”选择实际采集历史或明确的正常模拟参考，配置窗口/alpha等，查看作业和报告，再人工发布。实际采集历史不足时应失败，不能自动回退。
3. 注入温度尖峰观察GPU/HBM；功耗突增观察功耗；活动下降观察GPU利用率；显存活动下降观察mem_util。恢复正常后等待有效证据解除。
4. 查看分数、预测残差/水平分量；切换缺失场景检查未知保持，不将未知当正常。
5. 修改运行确认数，观察新修订重新计数；在模型库比较版本/回放，验证历史结果保留。正常空闲/高负载可能被单指标模型报告统计变化，不将其宣称硬件故障。

## 页面可理解性更新（0.6.1）

入口统一为“使用已训练的基线”和“重新学习历史基线”，导航“模型与训练”改为“基线与训练”。单指标默认使用动态基线检测，检测方法选择和算法参数收在折叠高级设置中；历史水平偏离明确标记仅评分、不生成动态参考。内部算法标识不变，既有模型和训练接口保持兼容。

基线列表/选择弹窗展示中文指标名称、按同设备/模板/来源历史排序的V编号、设备、训练来源、版本生成时间、历史范围和使用/自检状态；V编号是列表内展示编号，内部不可变ID保留在技术详情中。模拟参考、模拟采集历史和真实未核验历史分开标记。新训练记录实际数据窗口，老版本从分段报告恢复可用范围；没有记录时明确显示缺失，不编造。程序自检通过不等同故障准确率或真实生产准入。

已构建0.6.1，通过统一experiment.sh start更新服务，未创建新启停脚本。51项后端回归、新增可读性/来源/版本排序/高级设置/空状态契约、实际API载荷七页渲染契约均通过。浏览器验收通道不可用，人工点击/视觉效果仍待检查。
