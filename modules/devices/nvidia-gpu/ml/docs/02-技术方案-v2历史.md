# GPU机器学习异常检测技术方案 v2

更新：2026-11-12。本方案替代旧版三个固定检测目标方案；[旧方案](02-技术方案-v1历史.md)仅保留为历史记录。本模块只负责机器学习异常检测及结果输出，GPU告警事件关联、去重、合并与通知由夜莺及其告警处理链路负责。当前完成下面定义的实现版本，不代表真实H100生产准入通过。

## 1. 配置与模型的关系

检测配置单位为“GPU实体＋指标或不可变指标组”。选择设备范围、指标、单指标/联合类型后批量生成配置，重复提交幂等；已退役配置不自动重建。每条时序维护独立检测状态。算法可以共享，当前模型制品仍逐GPU配置训练；跨GPU共享权重、自动聚类/分组训练尚未实现。没有统一的GPU检测目标固定数量，也不要求先枚举所有故障目标。

单指标覆盖数为GPU数×所选指标数，联合覆盖数为GPU数×所选指标组数。指标字段存在不代表数据有效，不可评估状态必须显式展示。支持选择温度、显存温度、功耗、SM/显存时钟、利用率、显存控制器活动和显存使用量；字段全集不是默认全部启用的生产建议。

## 2. 单指标时序检测

算法标识`temporal_mad`：过去12个连续样本作为滞后特征，以Ridge预测当前点；预测误差使用训练期稳健MAD尺度归一化。同时对历史水平偏离独立评分，以避免持续偏移被滞后预测吸收。使用校准集归一化两个分量，取最大分量，校准阈值。历史水平项也可能把正常负载切换识别成异常，需要按工作负载分组和现场误报预算验证。

训练最少240个唯一源样本，按时间60%训练、20%校准、20%测试；每段窗口独立生成，不跨分割点学习。训练采样周期取源样本间隔中位数，窗口允许间隔偏差25%，拒绝跨缺口构建窗口。2秒周期对应过去约24秒，30秒周期对应过去约6分钟，窗口语义随模型制品一起固定，不混用不同周期模型。

在线先获取最新源样本时间，再按模型周期读取短窗口；模型只使用当前点之前的数据预测当前点，计算完成时间不作为结果时间。同一个源时间不重复推进状态。短窗口、缺数、陈旧、重复、不对齐不输出健康结论。恢复服务后短窗口从Prometheus重建；不会自动补算停机期间所有遗漏结果。

## 3. 可选多指标联合行为检测

算法标识`joint_pca`：按用户所选指标组构建不可变schema，使用训练集均值/标准差标准化，PCA保留d−1维。计算各指标重构残差及潜空间距离，用校准集分别定标并组合为异常分数。它是多变量联合点异常检测，不是时序预测，也不声称支持任意复杂非线性依赖。

灰线在此表示同一时刻联合重构参考，不能解释为预测正常值；不绘制虚假的预测置信区间。贡献指标表示重构残差分量，并另存联合距离分数；贡献不等于故障根因。标准化/降维/阈值仅从训练与校准分段学习，保留独立测试自检。无须故障标签即可拟合，但训练数据必须经过正常性审查。

每个指标组需重新训练模型；当前每GPU独立训练。指标组更改生成新schema与配置，不静默复用不兼容制品。联合检测不是强制能力，不预设“GPU必须三类检测目标”。

## 4. 数据与时间契约

沿用既有Prometheus只读接入、UUID/cluster实体身份和真实源时间查询；在线默认轮询2秒，源新鲜度15秒，必需指标时间差不超过2秒。联合结果时间取最早必需源时间。单指标直接使用该指标源时间。

SQLite results保存源时间、原始值、模型参考、分数、阈值、贡献指标、reference_kind、模型版本及检测类型，默认保留7天。训练快照与模型制品有摘要，可追溯与回滚。旧模型、旧任务与历史结果保留并标记legacy；新创建入口不使用旧三个模板。

## 5. 夜莺边界

ML输出每个检测配置的原始异常判断和持续确认状态，沿用3个新鲜异常/正常样本确认，重复源样本不累加、无效输入不解除已有条件。这里的episode仅是检测条件持续段，不是跨模型聚合的GPU事件。

夜莺实际创建/恢复事件并通知。固定结果网关输出UUID、cluster和detector_id，供告警侧按GPU和时间关联；本次未新增夜莺跨规则GPU事件合并组件，也不声称夜莺现有版本已自动实现该能力。页面显示夜莺实际返回的事件，不自行合成告警事件。

## 6. API与操作

`POST /api/gpu-ml/v1/policies`参数：entities数组、metrics数组、kind为univariate/multivariate。一次最多100张GPU、展开最多200项；默认不训练、不发布，重复提交返回skipped，退役后不自动重建。新模型必须从用户选择的Prometheus历史训练并审核测试报告后发布；无自动模拟回退。旧模拟bootstrap只保留用于旧链路回归。

Web路径：智能任务→批量配置检测→选择GPU范围/指标/类型→训练→报告→发布→在线曲线。多指标参考语义与单指标预测语义在曲线说明中区分。管理员/操作员/只读权限继续有效；演示角色直登沿用当前用户要求，生产部署关闭GPU_ML_DEMO_LOGIN。

## 7. 生产准入与工程限制

当前仍为单实例SQLite服务，在线窗口查询按任务执行；大规模设备/指标展开前必须评估查询负载与延迟，批量/缓存/分片和HA尚待实施。180/240样本门槛和10%测试异常率是程序自检，不是生产训练时长或准确率承诺。当前未做自动污染样本清洗、概念漂移重训、季节性模型选择、共享模型或GPU级总分。

生产准入需要现场数据验证采样周期、负载阶段覆盖、跨天稳定性、故障检出、正常负载误报、告警量预算、查询容量和停机恢复。模拟测试及开源算法存在不能替代这些证据。
