# 检测器与流水线扩展接口 v3

仅支持安装期受控Python代码，不接收网页上传代码、pickle或任意推理URL。本轮独立实现Merlion式组织设计，没有安装或复制Merlion。

## 检测器协议

`detectors.py`的Detector协议提供fit(rows)、score_raw(rows)、window和reference_kind。输入为严格递增、唯一源时间的行：`{"t": 源时间, "values": {字段: 有限值}}`。StrictPreprocessor负责必需字段和时间检查，支持identity及训练集拟合的robust_scale，不插值；检测器接收预处理后的数据。

score_raw返回同源时间、raw_components非空字典（有限非负，越大越异常）、component_metrics映射、可选expected和bounds。时序模型允许只返回历史窗口之后的可评估点，但不可使用未来样本。检测器不得内置生产阈值、推进告警状态或自动修改在线模型。raw_score是最大原始分量，仅用于该检测器诊断，不承诺跨算法可比。

能力声明提供history_samples、reference_kind（none/causal_forecast/joint_reconstruction）、reference_band、metric_contributions、online_update、minimum_samples等。未实现的能力必须为false/none。当前全部检测器无在线更新；新增有状态适配器前必须实现模型检查点与源水位的一致性，不能只将标志改为true。

受控注册：

```python
from gpu_ml.detectors import BaseDetector, register_detector

class InstalledDetector(BaseDetector):
    # 实现fit、score_raw与真实能力声明，不在这里设置阈值。
    pass

register_detector('installed_detector', '安装期自定义检测器', InstalledDetector)
```

模板algorithms必须显式允许该名称，注册在构建流水线/加载制品前执行。示例不是可用检测算法。自定义适配器需要独立效果、因果性和兼容性测试。

## 流水线与制品

DetectionPipeline组合预处理、检测器、QuantileCalibrator和ThresholdPolicy。fit只允许训练段拟合预处理/检测器，校准段拟合分量尺度和阈值；比较段/最终测试段只评分。predict返回raw_components、raw_score、calibrated_components、calibrated_score、threshold、anomaly和组件版本身份，expected/bounds反变换回原单位。

schema3制品包含组件与配置。save返回摘要；load_artifact在反序列化前核对SHA256并限制可信本地类型。schema1旧GPUModel保留独立兼容入口，不能根据旧score反推原始分数。新score-only检测器不会伪造参考线或根因贡献。

## 版本与评估

`postprocess`保持检测器/预处理参数不变，创建新pipeline_id/decision_id；重新校准才改变calibrator_id。父版本和训练快照复用且校验摘要。新版本只在手动发布后生效，旧在线状态和结果保留。

冻结集成取各成员score/threshold的最大值，成员必须同源、同切分并通过自检，复制进制品后不跟随成员外部修改。集成无参考线，不能嵌套。候选比较不自动选赢家；最终测试不参与排序。回放labels仅用于报告，不作为模型特征。
