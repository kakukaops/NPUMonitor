# GPU ML 实现与验收报告

日期：2026-11-11。版本：0.1.0独立系统预览。GPU专项代码已经实现，不再只有设计文档；本报告明确区分功能实现、实验链路和真实生产准入。

## 1. 功能与目录

| 目录 | 已实现内容 |
|---|---|
| `backend/gpu_ml/` | API、角色会话、源适配、质量、模型、训练与推理、持久状态、夜莺适配、固定结果网关、备份与恢复 |
| `frontend/` | GPU总览、在线曲线、任务、模型、训练/回放、事件反馈、平台审计 |
| `config/bindings.json` | GPU字段语义、单位/有效范围、三种模板和必需输入 |
| `deploy/compose.yaml` | 独立服务与卷，加入已有实验网络，端口19460 |
| `tests/test_core.py` | 模型、质量、源时间、重启状态、扩展适配及初始化保护 |
| `scripts/` | 构建/启动/令牌/同步/验证，以及管理和重启补充验收 |
| `evidence/gpu/` | 本GPU模块的冻结验收，不与旧通用demo证据混淆 |

首版前端使用无CDN依赖的原生JS和Canvas实现，替代原计划的React打包方案以减少预览部署依赖；API和页面分离，未引入夜莺前端分支。服务端采用FastAPI、固定scikit-learn依赖与SQLite WAL。该调整不意味着浏览器视觉验收已通过。

## 2. 已验证的链路

实际链路：GPU模拟指标 → 当前夜莺所用Prometheus → 独立只读推理 → 持久状态网关 → 夜莺实际事件 → 现有本地Webhook接收器。

不是由前端预绘曲线，也不是模型服务自己伪造夜莺事件。模拟来源和真实未核验来源均在页面区分。

四类首轮在线注入已通过：温度尖峰、缓慢热漂移、功耗/时钟关系异常和运行上下文中的活动下降。温度异常期间移除输入后同一夜莺事件ID/hash保留，新鲜正常证据后解除。具体耗时和事件身份见机器可读记录，不将实验秒数作为生产SLO。

已完成管理验收：

- 匿名拒绝、三角色访问、viewer写操作拒绝、跨站请求拒绝、HttpOnly会话。
- 正常高负载与正常空闲反例；空闲不直接称训练失败。
- 从当前Prometheus历史训练MAD版本，304个有效样本，排除33个已知模拟故障样本。该历史仍是模拟GPU遥测，不是实体H100训练。
- 新版本影子运行不切换在线模型；发布和回滚保持历史与稳定任务身份。
- 88点离线回放与在线事件隔离。
- 新任务复用已训练兼容模型、改名保持同一夜莺规则ID、退役保留历史。
- 数据库、制品、快照备份及空目录离线恢复通过。

真实容器重启验收：缺数保持期间重启新增服务，原活动夜莺事件、hash、episode和模型版本保留；有效正常数据后恢复。不是仅重新创建一个Python对象的单元测试。

## 4. 当前能力边界

- 只有三种GPU模板，其他型号、MIG实例、稀疏互联计数模型、作业根因分析与自动修复不在本版本。
- 历史数据不足会失败，不自动回退模拟或伪造14天历史。模拟健康冷启动和实际Prometheus历史模型分别标注。
- 结果网关仅实现固定查询契约；不是完整Prometheus。质量和平台故障独立告警，严格恢复通过持久状态与实际事件验证。
- 本版本自动通知绑定仅接受已有本地测试接收器；生产组织/通知配置仍需现场适配。
- 独立鉴权按本机角色令牌实现，未声称与夜莺登录互通或具备跨租户权限隔离。
- HTTP/ONNX任意模型上传不是已支持能力；提供受控Python适配注册与MAD示例。
- 阈值和图表参考带不是故障概率或真实生产准确率。

运行与接入步骤见[运行指南](05-运行与接入指南.md)，最终验收摘要和版本摘要见[GPU证据目录](../evidence/gpu)。后续真实准入以新的证据单列，不覆盖本次模拟记录。

## 5. 最终补充验收与复现

最终镜像部署后，`/ready`通过，当前活动ML异常数为0。反馈起止窗口保存与非法窗口拒绝通过。10项核心单元测试全部通过；纯Node DOM契约测试覆盖六页渲染和显式原始指标选择，通过，但不替代浏览器视觉/点击验收。目录检查通过：278份归类资产、45份冻结载荷、10个公共视图均保持一致。

平台故障测试实际暂停推理：过期业务查询返回503，夜莺产生平台告警，原业务事件235保留。恢复推理后业务/平台恢复；缺数产生独立质量事件239，恢复新鲜输入后解除。冻结记录见`evidence/gpu/platform.json`。本次测试为单实例实验，不代表生产可用性SLO。

以下命令在仓库根目录执行；在线验收会切换模拟场景，应串行运行：

```bash
bash modules/devices/nvidia-gpu/ml/scripts/gpu-ml.sh test
bash modules/devices/nvidia-gpu/ml/scripts/gpu-ml.sh verify
docker compose -f deploy/nvidia-gpu/ml/compose.yaml exec -T gpu-ml python < modules/devices/nvidia-gpu/ml/scripts/verify_management.py
python modules/devices/nvidia-gpu/ml/scripts/verify_restart.py
docker compose -f deploy/nvidia-gpu/ml/compose.yaml exec -T gpu-ml python < modules/devices/nvidia-gpu/ml/scripts/verify_platform.py
python scripts/check_module_layout.py
```

`evidence/gpu/summary.json`列出验收范围；`manifest.json`记录交付源文件摘要。历史训练样本数量取决于当次Prometheus数据积累，复验不应硬编码为304。
