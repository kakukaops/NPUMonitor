# v3流水线实施与验收

日期：2026-11-12。方案见[技术方案](02-技术方案.md)。本轮借鉴设计，未引入Merlion运行依赖。

## 实施范围

新增detectors.py、pipeline.py、evaluation.py；扩展训练、后处理版本、候选比较、集成、回放API及Web。旧制品和历史仍可查询、运行与回滚。Merlion研究报告/笔记已归入本ML模块的reports/research_notes，保持仓库模块目录边界。

## 验证

本轮证据目录为`evidence/gpu-v3/`，旧v1/v2证据不当作本轮自动通过依据。最终实测结果在收尾后补充，不将实现或单元测试等同真实GPU准入。

## 使用

1. 智能任务→批量配置检测→选择GPU范围/指标。
2. 训练→选择算法、训练范围、预处理和适用历史窗口，查看报告后发布。
3. 模型与训练→校准/阈值，可新建版本而不重训；查看报告后手动发布。
4. 智能任务→候选比较→比较报告。算法使用同一快照，不自动替换在线模型。
5. 需要时创建集成，选择同源同切分且自检通过的成员；查看集成报告后发布。
6. 回放可选择已登记反馈窗口为标注，无标注不计算误报率/召回率；不会写入在线事件。
7. 图例按能力展示：预测、重构或仅评分；无能力不绘制灰线和区间。

## 复现

```bash
bash modules/devices/nvidia-gpu/ml/scripts/gpu-ml.sh test
docker compose -f deploy/nvidia-gpu/ml/compose.yaml exec -T gpu-ml python < modules/devices/nvidia-gpu/ml/scripts/verify_v3.py
python scripts/check_module_layout.py
```

在线验收只允许显式模拟环境，会临时注入异常。训练是否通过仍取决于当次历史，不跳过自检门槛；单实例容量、真实硬件及浏览器视觉准入单列。
