# 模型平台内部接口契约 v1

这是本系统的适配器协议，不是公司原生API约定。Python端口：[contracts.py](../backend/gpu_ml/model_backends/contracts.py)，HTTP参考适配：[http.py](../backend/gpu_ml/model_backends/http.py)，独立服务：[model_platform](../../../../model-services/reference-platform)。所有非health请求需要内部Bearer令牌，凭据来自文件，不放URL或模型元数据。

## 任务

POST /v1/jobs：contract_version=1、request_id幂等键、operation及操作体。相同键/相同输入返回原任务，相同键不同输入409。GET /v1/jobs/{id}查询，POST /v1/jobs/{id}/cancel协作取消。状态queued/running/completed/failed/cancelled；监控侧另有pending_sync表示RPC未知或重启恢复中。

fit操作体：

```json
{
  "contract_version": 1,
  "request_id": "monitor-generated-id",
  "operation": "fit",
  "training_spec": {
    "template": "logical-template-id",
    "algorithm": "logical-recipe-id",
    "feature_schema": {},
    "source_type": "simulated",
    "entity": "cluster|GPU-UUID",
    "pipeline": {},
    "labels": []
  },
  "dataset": {"sha256": "canonical-json-sha256", "rows": []}
}
```

rows为t＋values，实际数据必须满足模板、数量、时间、profile和摘要检查；空数组只是结构示意，不是有效任务。参考实现使用sort_keys、紧凑分隔符、禁止NaN的JSON计算摘要。标签用于评价，不作为特征。请求不携带Python代码、下载URL或pickle。

postprocess操作体带platform_id、model_ref、可选calibration/factor；ensemble带platform_id、models数组与factor。后端可声明不支持这些操作，适配器应明确返回unsupported，不能静默在监控进程重训。

completed任务result包含platform_id、model_ref、dataset_sha256、algorithm、feature_schema、source_type、report、capabilities、pipeline及status。监控复核schema/摘要/报告/能力，登记本地版本引用，不接收新权重文件。

## 部署与推理

POST /v1/deployments：model_ref＋platform_id。返回稳定deployment_ref，参考实现按平台与模型生成幂等部署身份。只有回执身份正确且已就绪后，监控才切换在线指针。预览回放用POST /v1/models/{model_ref}/predict；在线用POST /v1/deployments/{deployment_ref}/predict。

请求：platform_id、rows、decision_factor。响应：contract_version、platform_id、model_ref、deployment_ref、quality、points。quality为valid/warmup/history_gap/outside_reference/reference_window_incomplete。有效响应必须包含最新输入源时间；point时间必须是输入的有序子集，原始values不能变化。

point基本字段：t、values、score、threshold、anomaly；可选raw_score、raw_components、calibrated_score、expected、bounds、contributions、evidence及组件版本。score/threshold有限，threshold>0，anomaly须与比较结果一致。没有预测/重构能力时expected/bounds为空，不伪造灰线；分数不是故障概率。

capabilities至少包含history_samples、cadence_seconds、reference_kind；当前参考模型不在线更新。公司适配器须正确声明窗口与更新语义，不能靠修改标志就启用有状态增量更新。

## 企业适配方式

方式A：实现ModelBackend端口，调用公司原生API/SDK，返回标准化结果。

方式B：提供轻量HTTP桥接层，实现以上协议，再通过GPU_ML_MODEL_PLATFORM_URL配置桥接地址。只有协议兼容桥接可直接换URL；不能把任意公司模型URL直接填入并期望可用。

认证、模型标识、数据上传、错误码、同步/异步部署、响应转换由适配器负责。公司仅提供原始预测时，需要明确由哪一侧执行预处理与后处理，校准和模型版本必须绑定。错误返回未知，禁止异常时回填0或正常值。
