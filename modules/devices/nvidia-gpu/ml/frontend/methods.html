SHADOW ONLY
◉
热限制与温度余量温度接近设备门槛 + 热限制原因位
↗

同卡温度距设备运行门槛 ≤ 5°C，且 thermal clocks event reason 位有效。需要设备门槛与原因位同时存在，否则 unknown。本轮 GWDG 回放未评分。

▥
显存容量压力低空闲容量 + 有显存活动
↗

显存可用比例 ≤ 5%，同时 MEM_COPY_UTIL ≥ 50%。正常预分配也可能满足，不能直接称显存泄漏。GWDG 事件前两小时命中 1/50 个窗口。

⌁
同节点活动分离利用率、功耗、驻留显存联合判断
↗

目标卡利用率 ≤ 10%，至少两张同节点卡的利用率中位数 ≥ 80%，目标功耗 ≤ 同伴一半且显存仍有驻留。没有作业 / rank 对齐时不能称慢卡。GWDG 事件前两小时命中 2/50 个窗口。

当前结论

可信的下一步是把规则与条件模型作为明确证据，把动态 PCA 作为待复核候选。公开数据还不能证明真实 GPU 故障精度；上线通知前需要连续正常机群、人工确认事件和每 GPU 天告警预算。
