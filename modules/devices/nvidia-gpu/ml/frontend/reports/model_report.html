1. 方法介绍

可以把模型理解成“自动排查员”：先把一段监测曲线整理成当前水平、近期变化和缺测情况，再给出异常分数；分数超过阈值就报警。单指标只看一种DCGM变量及其历史统计；多指标同时看18种变量。

监督模型需要正常和故障样本来学习。无监督方法（XID=0参考）仅用历史当前XID确认0的窗口拟合正常参考，不需要故障正样本；它仍借助XID=0筛选参考数据，不能叫“完全无标签”。本报告不包含完全无标签建立参考的实验。

L2逻辑回归

监督

适用范围：仅单指标

把当前值、近期均值、变化趋势等信息按权重相加，得到异常分数。L2约束限制某个权重过大，减少对个别现象的过度依赖。

r(x) = b + ∑j=1…d wjxj
S(x) = σ(r) = 1 / (1 + e−r)

wj是第j项标准化历史统计的权重，b是基础分；wjxj是这一列在本次打分中的贡献。σ把加权总分转换到0～1。比如r=1时，S≈0.731。报警仍要和验证节点选定的阈值τ比较；这个分数没有经过客户现场概率校准。

L2与训练中的正样本权重是什么
J = ∑i qi ℓ(yi, S(xi))
　　+ (λ / 2) ∑j wj2
ℓ(y,p) = −y ln(p) − (1−y) ln(1−p)

训练会寻找使J更小的权重。第一项衡量分类偏差；第二项就是L2惩罚，限制权重过大。λ控制惩罚强度，实验参数C越小，惩罚越强。y=1表示XID异常，y=0表示确认0；本次qi对正样本取2、负样本取1。基础分b在此L2逻辑回归实现中不受惩罚。

白盒 · 能查看哪些输入把分数推高；正负权重都要结合当前数值解释。

梯度提升树

监督

适用范围：仅单指标

一轮轮增加小决策树，后面的树重点修正前面的判断偏差，最后形成一个综合异常分数。

F0(x) = b
Fm(x) = Fm−1(x) + η fm(x)
S(x) = 1 / (1 + e−FM(x))

fm(x)是第m棵小树给出的修正值，可以为正或负；η控制每次修正的幅度，本实验为0.05；M是树的总轮数。把各轮修正累加到基础分b，再转成0～1的分类分数。后续树根据前面模型的偏差继续学习，训练也使用正2、负1的样本权重。

黑盒，可辅助解释 · 能学习复杂的组合关系，但现场解释通常需要额外的贡献分析。

浅层决策树

监督

适用范围：单指标＋多指标

像一个较短的排查流程：先检查某项统计值是否超过界限，再沿分支继续判断。本实验限制树的深度，方便查看判断路径。

xj ≤ c：走左分支；xj > c：走右分支
S(x) = 2N1(L) / [2N1(L) + N0(L)]

沿条件一路走到叶子L，也就是最终落到的那一类情况。N1(L)和N0(L)是训练时落到该叶子的异常、正常样本数。因为异常样本权重是2，叶子得分使用加权比例。比如10个异常、30个正常，得分为20/(20+30)=0.4。分支阈值c决定走哪条路；报警阈值τ决定这个叶子得分是否发出报警。

白盒 · 可直接展示本次经过的条件，例如某指标缺测比例或近期变化超过阈值。

PCA＋逻辑回归

监督

适用范围：仅单指标

先把互相关联的历史统计压缩成少数几个变化模式，再用逻辑回归区分正常和异常。整个方法仍需要故障标签。

z = VKT(x − μ)
S(x) = σ(b + ∑k=1…K βkzk)

μ是该监督模型训练样本在x空间的平均向量，包含正常和异常窗口；VK保存K个主要变化方向，上标T表示矩阵转置。zk是当前窗口在第k种变化模式上的位置，βk是逻辑回归给这个模式的权重。先压缩，再用模式的位置做分类。

w等效 = VKβ

这组等效权重可以把模式上的打分追溯回原来的历史统计列。这里的“原来”仍指标准化后的x列；若要换成温度、功率等原量纲，还要还原标准化处理。

可解释的组合模型 · 可从压缩后的模式追溯原输入；比直接逻辑回归多一层转换。

PCA T²

无监督 · XID=0参考

适用范围：单指标＋多指标

先学习正常变化模式，再看新数据在这些模式上的位置是否远离正常中心。即使模式没变，偏离过大也可能报警。

μ0 = (1 / |R0|) ∑i∈R₀ xi
zk = vkT(x − μ0)
S(x) = T2 = ∑k=1…K zk2 / λk

R0是训练节点中当前XID确认0的参考窗口集合，|R0|是窗口数。μ0是正常参考窗口在标准化特征空间中的平均向量。vk是正常变化方向，λk是正常数据沿该方向的方差。

zk2/λk表示“这次偏离相对于正常波动有多大”，再把保留方向的偏离相加。正常时几乎不变化的方向，出现同样幅度的偏移会更加显眼。本实验按正常参考方差累计解释比例约95%选取方向，报警阈值另由验证节点确定。

异常分数可拆解 · 可拆解哪些模式或指标推动分数，说明数据在哪些正常变化模式上偏离较大。

孤立森林

无监督 · XID=0参考

适用范围：仅单指标

用许多随机划分尝试把样本分开。与正常参考中的大多数样本很不同、较容易被单独分出来的样本，异常分数较高。

h̄(x) = (1 / T) ∑r=1…T hr(x)
S(x) = 2−h̄(x) / c(ns)

T是随机树的数量，本实验为100。hr(x)是第r棵树把当前样本分到叶子所需的划分次数，并对叶子内仍有多个参考样本的情况作修正；它不是监测时间或30个时间步。ns是每棵树使用的正常参考子样本数，本实验最多256；c(ns)是与这个样本规模对应的路径长度归一化因子。

越容易被单独分开，h̄越小，分数反而越高。例如归一化因子为10：平均只需5步时S≈0.707，平均需10步时S=0.5。实现中取库函数score_samples的相反数，让“越异常、得分越高”；随后使用本报告选定的τ报警。

黑盒 · 擅长发现不常见的组合；分数本身不说明具体的硬件故障原因。

稳健参考范围

无监督 · XID=0参考

适用范围：单指标＋多指标

为每个历史统计量建立典型水平和波动尺度，再计算当前偏离有多大。本实验取各项标准化偏离中的最大值作为报警分数。

m0j = mediani∈R₀(xij)
MADj = mediani∈R₀|xij − m0j|
rj = max(1.4826MADj, 0.1σ0j, 10−6)
dj(x) = |xj − m0j| / rj
S(x) = maxj dj(x)

仍只使用R0中的XID=0参考。m0j是第j列的正常中位数；MADj表示参考数据偏离中位数的典型幅度；σ0j是这一列参考数据的标准差。rj取三项中的最大值，后两项是当前实现的尺度下限，避免参考波动接近0时把微小偏差无限放大。

Dg(x) = maxj属于指标g dj(x)

先算每列“偏离了多少个参考尺度”，再取最大值作为联合分数。多指标时，把同一DCGM变量所属统计列的偏离取最大值，得到Dg；可以据此指出哪个变量推动报警。这里也包含缺测统计，定位的是模型依据，不是物理故障原因。

白盒 · 可指出哪一项偏离最大，以及它偏离正常参考多少；缺测统计也可能是依据。

本报告单指标仅保留上述7种方法；多指标仅保留浅层决策树、稳健参考范围、PCA T²这3种方法，与网站部署范围一致。白盒或可解释分数能够说明“模型为什么报警”，不能单凭模型贡献确定“哪个指标造成了XID硬件故障”。

颜色越深，所选性能越高；点击任意格子可查看下方详细结果。它是探索性比较，不是新的独立验证。

即使本指标当前缺失，只要其他DCGM指标仍有有效数值，窗口也会保留；本指标模型可能通过它自己的缺测统计报警。GPU温度或功率报警表示该变量的模式与XID异常相关，不等于已确认温度或功率是故障原因。

4. 持续报错，不能只看逐窗口recall

一段持续1小时的XID异常大约贡献360个正窗口。模型即使晚发现，也可能获得不错的窗口recall。因此另看“开始报错的那个10秒端点，是否已经检出”，每个起始只算一次。

前两项问“第一时间发现了吗”，第三项问“这段报错最终发现过吗”。45、59、86分别是各自可评价的片段总数，不是已经检出的数量，也不是三类互斥故障。

评价指标分母包括哪些片段什么情况下算命中
明确起始当刻检出 / 4545个片段：前一个10秒端点确认XID=0，当前变为非零，且当前可评价。就在这个0→非零的端点报警才算。用于看可确认的状态转换是否及时检出。
首次观测当刻检出 / 59上述45个，加上14个此前有采集空白、实际开始时间不够明确的片段；首次看到非零的端点都可评价。在该片段第一次看到非零XID时报警就算。它可能已经报错一段时间，不能一律称为真实开始。
报错期间曾检出 / 8686个片段内至少有一个XID非零且可评价的端点；即使开头无法评价，后面仍可能有数据。任一可评价的非零XID端点报警一次就算。晚几分钟才检出也算，所以不能用它证明发现及时。

这批数据的包含关系：59 = 45个明确起始 + 14个起始不确定；86 = 59个首个观测端点可评价 + 27个开头不可评价、后续才有可评价数据的片段。每个片段在同一个指标内最多计一次。

示意例子：10:00开始报错，10:03才报警

时间09:59:5010:00:0010:03:00
XID状态确认0首次非零仍然非零
模型输出未报警未报警首次报警

假设这些时刻都有可评价数据：这一片段在“明确起始当刻”与“首次观测当刻”均未命中，但在“报错期间曾检出”中命中。如果10:00就报警，则三项都命中。

如果10:00之前的XID采集有空白，无法确认上一条10秒记录为0，那么这段不进入45的分母；只要10:00首次非零时可评价，就可以进入59和86。这里的“首次”指每个已定义报错片段的第一个非零观测，不是该节点整个数据集里只取一次。

明确起始Recall = 起始端点报警的次数 ÷ 可评价的明确起始次数（45）

45次明确起始分布在8个节点；前一个10秒端点确认XID=0，当前非零。它们全部有可用DCGM输入。它们是数据中观测到的XID状态转换，仍不是硬件物理故障时刻的直接证据。

precision、recall都针对XID异常正类

Precision = TP ÷ (TP + FP)
发出的报警里，有多少在当时确实观测到XID非零。

Recall = TP ÷ (TP + FN)
所有保留的XID异常窗口里，模型检出了多少。

F1 = 2TP ÷ (2TP + FP + FN)
综合precision和recall；两者都高时F1才高。

如何读数

TP是异常且报警；FN是异常却没报；FP是报警但XID确认0或未知。表格同时拆出“确认0的FP”和“XID未知的FP”。

测试FPR = FP ÷ (FP + TN)，按本页运维口径包含未知状态。校准阈值时只用XID已知的验证窗口，FPR分母为确认0的窗口。

这些是汇总所有留出节点窗口的正类指标，不是类别宏平均，也不是节点宏平均。完美检出且无误报时P、R、F1均为100%；从未报警时precision显示“—”，不写成100%。

未知XID计FP是偏保守的运维约定，不证明这些GPU实际正常。连续6个10秒误报算6个FP窗口，不等于6次独立事故。

输入特征、节点划分与训练设置
过去5分钟 → 历史统计 → 当前检测

每个输入含30个10秒端点，范围是(t−5分钟,t]，最早端点为t−290秒。每项指标先得到GPU间均值、GPU间最大值、缺测GPU比例，再形成28列历史统计；单指标28列，多指标18×28=504列。

数值通道各10项：当前值、30/60/300秒均值、300秒最大/最小/标准差、最近60秒减前240秒均值、60/300秒斜率。缺测通道8项：当前、30/60/300秒均值、最大值、近60秒与前240秒差、全缺比例、连续全缺秒数。XID、节点ID和未来数据均不进入特征。

按节点隔离，而不是随机打散重叠窗口

原19个节点固定分成5组；每轮1组测试、下一组验证、其余3组训练，轮转5次。模型始终在未用于训练或调阈值的节点上接受测试。排除缺测后保留15个节点，仍沿用原分组。

监督训练保留全部正样本，负样本最多取正样本3倍，正样本权重2、负样本权重1。无监督模型只用训练节点当前XID=0的窗口建立参考。验证与测试不做正负重采样。
